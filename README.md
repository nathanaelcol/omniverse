# OMNIVERSE : Le Dernier Créateur

Jeu original jouable dans le navigateur. Tu explores le Point Zéro, tu changes la chute d'un lieu, tu traverses deux réalités, et tes choix restent dans la sauvegarde.

## Jouer

[https://nathanaelcol.github.io/omniverse/](https://nathanaelcol.github.io/omniverse/)

En local :

```bash
npm install
npm run dev
```

Puis ouvre l'adresse affichée par Vite. `npm test` vérifie la gravité et l'écologie. `npm run build` produit le site dans `dist/`.

## Contrôles

- ZQSD ou WASD : marcher
- Souris (clic sur le monde) ou flèches : regarder
- Espace : sauter. Dans l'eau, monter
- Ctrl : se baisser. Maj : courir
- E : interagir. F : frapper
- G : lois. B : construire
- Échap : fermer un panneau, ou pause

La gravité ne change qu'à l'intérieur d'une ancre, et l'ancre est petite.

## Cette version

Ouvert et jouable : Point Zéro, Monde des Géants, Monde inversé, éditeur de réalité, créatures, deux civilisations, anomalies, construction, jardins créés, sauvegardes, boss et cinq fins.

Nommé sur la carte, pas encore jouable : Océan infini, Civilisation éternelle, Royaume des rêves, Monde sans temps, Jardin du Néant, Infini brisé. Les jardins de l'atelier sont une écologie simplifiée, pas une évolution complète, et pas ces univers-là.
